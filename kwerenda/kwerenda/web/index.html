1What to look for

Operators: AND OR NOT, parentheses, "phrases", NEAR/10, field:term. A trailing * matches inflected forms, ** truncates.
The script decides: a Cyrillic term is never expanded with German endings. Fewer languages means less noise.

2Where to look

auto walks down the ladder: WordPress REST API → Drupal JSON:API → sitemap → RSS → the site's own search → link crawl. Every hit is then confirmed against the full article text.
If a site's own search is bad, don't fight it: give a listing template (an archive page with {page}, optionally {year}) and the whole archive gets walked instead.
